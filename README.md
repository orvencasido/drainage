# Drainage Management System

An integrated flood reporting, drainage monitoring, and infrastructure management system.

## Repository Structure

- **`drainage-user-flutter/`**: Flutter mobile application for citizens and users to report drainage and flooding issues.
- **`drainage-admin-react/`**: React web administration dashboard for dispatchers, operations, and municipal management.
- **`backend/`**: Supabase database schemas, SQL functions, triggers, and deployment configurations.
- **`automations/` & `automations-bp/`**: Operational simulation scripts, report generation, and automated workflows.
- **`new-automations/`**: Extended simulation scripts and scenario data.
- **`assets/`**: Shared documentation and media assets.
